# Priv Philanthropy

A standalone, static landing site for Priv Philanthropy. The page introduces the live giving platform and its long-term community-investment vision, including a pathway drawn from the legacy Priv social-impact roadmap.

The legacy roadmap's pilot dates and reported metrics were not carried forward because the source page identifies them as placeholders and they have not been independently verified.

## Run locally

Open `index.html` directly, or serve this directory with any static file server.

## Deploy with Vercel

Import this repository as a static site. No framework preset, install command, build command, environment variables, or output directory are required. The entry page is `index.html` at the repository root.

The page links to the live product at `https://privphil.sansmercantile.com` and routes mobile-launch notifications to the existing Sans Mercantile contact page.
